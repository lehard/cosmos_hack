# contracts — единый источник контрактов `ant`

Всё, что здесь лежит, — закон для остальных эпиков (эпик 00, AD-20, AD-40). Код, типы Go и TS,
клиент API и XSD генерируются из этих файлов (`make generate`, эпик 02); руками сгенерированное не правится.

## Имена

- Тип события — `семейство.сущность.действие`, три сегмента латиницей; семейства и владельцы — `events/catalog.yaml` (AD-40). Имена типов не кодируют результат контроля: `inspection.result.recorded`, а не `inspection.result.failed`.
- Схема данных типа — `events/‹семейство›/‹тип›.v‹N›.json`, `N` — мажорная версия (`schema_version`).
- Поля — `snake_case` латиницей; значения перечислений — `snake_case`; `description` — по-русски, термины из словаря продукта.
- `$id` схемы — `https://ant.invalid/contracts/‹путь от contracts/›`: повторяет путь файла, по сети не загружается; ссылки `$ref` — относительные пути файлов.

## Диалект JSON Schema (AD-20)

Подмножество draft-07, чтобы одинаково работали `go-jsonschema`, `json-schema-to-typescript`, `santhosh-tekuri/jsonschema` и Ajv:

1. `"$schema": "http://json-schema.org/draft-07/schema#"`, у корня — `$id`, `title` (имя генерируемого типа) и `description`.
2. Нет `type: number` — только `integer` (доли — базисные пункты `*_bp`, измерения — целое + масштаб + единица; AD-4). Целые — в пределах ±(2^53−1).
3. Нет `format: date | time | duration` — `date-time` или строка с `pattern`.
4. Нет `oneOf`, `anyOf`, `allOf`, `not`, `if/then/else`, `dependencies`: полиморфизм — через `event_type` и отдельные схемы. «Может отсутствовать значение» — `type: ["string", "null"]` у простых полей.
5. Схемы событий **открыты**: `additionalProperties: false` запрещён — новое необязательное поле принимается и сохраняется (FR-29). Схемы подписываемых документов, записи журнала и внутренних сообщений **закрыты** (`additionalProperties: false` у каждого объекта; AD-10).
6. У каждого свойства, кроме `$ref`, есть `description` на русском.
7. Имена свойств — `^[a-z][a-z0-9_]*$`; значения `enum` — строки `^[a-z][a-z0-9_]*$`.
8. Все `$ref` разрешаются в пределах `contracts/`.

Линтер диалекта — `scripts/lint-schemas.mjs`, часть `scripts/check.sh`.

## Как добавить или изменить тип

1. Строка типа в `events/catalog.yaml` (эмитент — модуль-владелец семейства; вид, поток, ось, класс, критичность, `guard_relevant`, `publish_stage`, происхождение, версии).
2. Схема `events/‹семейство›/‹тип›.v1.json`.
3. `node contracts/scripts/asyncapi.mjs --write` — пересобрать `events/asyncapi.yaml` из каталога.
4. `contracts/scripts/check.sh`.

Совместимое изменение (новое необязательное поле, новое значение перечисления, новый тип в своём семействе) модуль делает сам. Несовместимое — только новой мажорной версией `‹тип›.v‹N+1›.json` и повышателем v‹N› → v‹N+1› (эпик 02), через дирижёра. Пример — `events/equipment/equipment.state.changed.v1.json` → `.v2.json` и `events/examples/`.

## Проверка

```sh
contracts/scripts/check.sh          # из корня репозитория
```

Нужен Node ≥ 20 на хосте или Docker (тогда проверка идёт в `node:24.21.0-slim`). Зависимости проверок закреплены в `scripts/package.json` и `package-lock.json`.
