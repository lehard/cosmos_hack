# Контракт импорта условной сборки КОМПАС-3D (эпик 31)

Файл условной сборки — внешний формат модуля `cad` (FR-94, PRD §11.15, AD-18; кейс §3.3, §5.3). Источник правды
для адаптера `backend/internal/infrastructure/integration/cad/kompas`; перевод в объекты нормативного слоя —
`backend/internal/domain/cad`; сценарий импорта — `backend/internal/application/cad`; описание обмена —
`docs/integrations/kompas.md`.

| Файл | Что это |
|---|---|
| `assembly.schema.json` | схема файла формата 1.x: сборка (`geometry: null` обязательно, с пояснением), позиции с количествами и деревом через `parent`, связи `weld` / `bolted_joint` / `seal` / `threaded_joint`, важные характеристики, правило сопоставления ID |
| `examples/kompas-assembly-flange.json` | эталон — сборка ФЛ-100.00.000 СБ, версия «Б», литера О1 (файл процессной сессии без изменений); контрактный тест `go test ./internal/infrastructure/integration/cad/...` |

**Операция:** `POST /api/v1/cad/assemblies` (`cad.assembly.import`, тело — имя файла и содержимое base64);
чтение — `GET /api/v1/cad/assemblies` (`cad.assembly.list`).

**Что делает импорт.** Файл проверяется схемой (нарушение — `400 api.validation_failed` с полем: нет `geometry`,
нет версии КД, пустое обозначение, связь на несуществующую позицию, дробный момент; неизвестная мажорная версия
формата — та же ошибка с пометкой «переобработка после повышателя»). Затем домен `cad` переводит сборку:

| Из файла | В нормативный слой (факт `cad.assembly.imported`) |
|---|---|
| позиции, `qty`, `parent` | дерево состава: наш тип изделия, родитель, количество на родителя и на сборку, учёт (`serial` / `lot` / `none`) — черновик справочника типов изделий (утверждает человек, AD-31) |
| `weld` W-1 | зона `W-1` (`weld_section`) и ограничение `rework_limit`: лимит из файла (`rework_limit`) или из ТП — шаг BPMN с `reworkLimitScope="zone"` и зонами `W-1.*` (для фланца — `welding.weld`, лимит 3) |
| `bolted_joint` J-1 | зона `J-1` (`joint`), ограничение `closes_access` — закрывает доступ к зонам уплотнений между теми же позициями (`S-1`) или к `closes_access_to`; шаг — тот, у которого `closesZoneAccess` содержит зону (`assembly.cover_install`); крепёж и порядок затяжки — `fastening` |
| `seal` S-1 | зона `S-1` (`groove`), ограничение `install_order`: уплотнение до позиции, которую закрывает болтовое соединение (крышки) |
| `threaded_joint` J-2 | зона `J-2` (`joint`), ограничение `torque` (момент, допуск, контровка) |
| обозначения КД | наши типы изделий по правилу ЕСКД (`domain/cad.ItemTypeID`: «ФЛ-100.00.000 СБ» → `FL-100.00.000`, «Болт М6×20 [П]» → `BOLT-M6-20`) и записи `reference.external_id.mapped` (система `kompas`) |
| номенклатура 1С (порт `Nomenclature`) | расхождения `not_in_erp` — отчёт без автосоздания; номенклатуры нет — одна запись `not_checked` |

Факты идут через обычный приём: источник `cad.kompas`, вид `import`, `event_id` факта импорта — UUIDv5 от
отпечатка файла (Стрибог-256): тот же файл повторно — дубль с прежней квитанцией (AD-7).

**Прямое подключение.** Экстрактор COM API7 (Windows-шлюз) или выгрузка состава из ЛОЦМАН:PLM пишут тот же
формат; меняется источник файла — адаптер, домен и ядро остаются.

Все значения эталона — проектные допущения процессной сессии (NFR-DOC-2).
