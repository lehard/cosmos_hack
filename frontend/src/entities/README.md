Слой `entities` (Feature-Sliced Design): одна папка на вид сущности из контракта SSE
(`EntityKind`). Здесь — обёртки над сгенерированным клиентом (`shared/api/generated`)
с ключами кэша по соглашению `shared/api/keys.ts`: `[сущность, id, …]` и
`[сущность, '@list', …]`. Только такие ключи инвалидирует канал живых обновлений,
поэтому виджеты читают сервер через `entities/*`, а не через сгенерированные хуки
напрямую. Каркас положил эпик 03; обёртки для своих экранов добавляют эпики 10–15.
