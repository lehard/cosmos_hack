# Мастер участка

Ваш стол — «Участок»: посты, операции, задачи; вкладки «Люди и оборудование», «Задачи», «Смена».

## Что важно
- Длительность операции видна против нормы, повторные обработки — против лимита.
- Исполнителей на посты назначаете вы — только допущенных по квалификации; контролёра — запросом с согласованием начальника ОТК.
