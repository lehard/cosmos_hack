# shared/ui — дизайн-система «Главный»

Минималистичный одноцветный enterprise (NFR-UI-2): нейтральная серая шкала, один
акцент — только для главного действия, ссылки и выбора; остальные цвета — тона
словаря статусов из контракта (`contracts/statuses.yaml`). Шрифты PT Sans / PT Mono
и значки `@vicons/tabler` — локальные.

## Токены — `theme/`

| Файл | Что там |
|---|---|
| `theme/tokens.ts` | единственный источник: нейтральная шкала, акцент, статусы, типографика, отступы, скругления, тени, ширины, плотность |
| `theme/naive.ts` | `themeOverrides` для корневого `NConfigProvider` и `densityOverrides(плотность)` для виджета |
| `theme/css.ts` | CSS-переменные `--ant-*` (ставятся в `main.ts` через `installTokens()`) и классы `.ant-density-‹плотность›` |
| `theme/base.css` | базовые стили документа и служебные классы |

В стилях виджетов — только переменные, без цветов и размеров руками:

- цвета: `--ant-text`, `--ant-text-2`, `--ant-text-3`, `--ant-border`, `--ant-border-strong`,
  `--ant-surface`, `--ant-surface-subtle`, `--ant-surface-hover`, `--ant-bg-app`,
  `--ant-accent`, `--ant-accent-soft`, `--ant-status-‹тон›`, `--ant-status-‹тон›-soft`,
  шкала `--ant-n-0 … --ant-n-900`;
- шрифт: `--ant-fs-body`, `--ant-fs-meta`, `--ant-fs-title` (зависят от плотности),
  шкала `--ant-fs-xs … --ant-fs-display`, `--ant-fw-bold`, `--ant-font-mono`;
- отступы и формы: `--ant-space-1 … --ant-space-12` (шаг 4 px), `--ant-gap`,
  `--ant-pad-section`, `--ant-pad-cell-x/y`, `--ant-radius-sm/md/lg/pill`, `--ant-shadow-sm/md/lg`;
- ширины: `--ant-w-auth`, `--ant-w-side`, `--ant-w-queue`, `--ant-w-header`,
  `--ant-w-drawer-min`/`--ant-w-drawer` (окно записи), `--ant-w-nav`/`--ant-w-nav-collapsed` (левое меню).

**Плотность** (AD-21) приходит из среза стола: `WidgetFrame` ставит класс
`ant-density-large | comfortable | compact` и вложенную тему Naive UI — внутри
виджета `--ant-fs-body`, высоты кнопок и полей уже нужного размера.

## Переполнение текста

Каждый текст неизвестной длины — в элементе с одним из классов:
`ant-ellipsis` (одна строка, многоточие; полный текст — в `title` или подсказке),
`ant-wrap` (перенос, в том числе длинных кодов), `ant-clamp-2` (две строки),
`ant-box` (сжимаемый контейнер для слота). Тест `__tests__/overflow.spec.ts`
проверяет это для всех элементов `shared/ui`.

## Какой элемент когда брать

| Элемент | Когда |
|---|---|
| `AppPage` | корень страницы в оболочке: заголовок, подзаголовок, действия справа (стол с одной вкладкой, справка, отдельные страницы) |
| `WidgetFrame` | корень каждого виджета на столе: заголовок, момент, режим `fixtures`/`live`, четыре состояния данных, действия (выключены в воспроизведении), плотность |
| `SectionPanel` | смысловой блок внутри виджета или страницы; `variant`: `card` — карточка, `subtle` — приглушённый блок, `plain` — только заголовок |
| `ToolBar` | ряд переключателей, фильтров, поиска над списком; слот `end` — действия справа; переносится, а не вылезает |
| `FormField` | поле формы: подпись, элемент управления в слоте, подсказка, ошибка под полем |
| `DataTable` | табличный список: `columns` + `rows` (+ слоты `cell-‹key›`) или своя разметка `<thead>/<tbody>` в слоте — стиль один |
| `KeyValueList` + `KeyValue` | реквизиты объекта «подпись — значение»; пустое значение — «—» |
| `EmptyState` | нет данных (факт о данных, не ошибка); `compact` — в узкой панели |
| `StatusTag` | статус из словаря статусов: мягкая плашка тона, текст по ключу словаря |
| `ActionButton` | кнопка с текстом неизвестной длины: `label`, `overflow="ellipsis"` (по умолчанию, с подсказкой) или `"wrap"`; прочие свойства — как у `NButton` |
| `BrandMark` | знак и имя «Главный»: шапка (`size="sm"`), вход (`size="lg" tagline`) |
| `WidgetStub` | заготовка виджета, который ещё не наполнен |
| `RecordDrawer` | правое окно записи (Д-70): щелчок по строке любого списка открывает запись справа — заголовок (тип, номер, статус), вкладки, нижняя панель кнопок действий; открытое окно — в адресе `?open=‹тип›:‹id›` (`shared/model/record`), содержимое по типам — реестр `app/record` |
| `SideNav` | левое меню разделов (Д-73): значок и подпись, развёрнуто по умолчанию, сворачивается в полосу значков, не скрывается; пункт один — меню не ставить |

Не брать: панели «под списком», реагирующие на выбор строки (вместо них — `RecordDrawer`),
вкладки `NTabs` для разделов стола (вместо них — `SideNav`), голые `<table>` со своими стилями, цвета `#…` в стилях виджета,
`NCard` как рамку виджета (есть `WidgetFrame`), `NButton` с длинной подписью без
`ActionButton`.
