# Документы «Главного»

Один список документов — [навигатор в путеводителе проверяющего](reviewer-guide.md#навигатор-по-решению): там у каждого
документа своя строка и своя задача. Ключевые документы и за что отвечает каждый — [README репозитория](../README.md#документы).

Служебное: `scripts/check-docs.mjs` проверяет ссылки и якоря, совпадение руководств со встроенной справкой, пути и
цели `make` в путеводителе, заголовки пакетов Go (NFR-DOC-3). Копии PRD и спайна обновляются из рабочей папки
планирования и называют систему рабочим именем `ant`; источник правды — сам код.
