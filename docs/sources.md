# Источники

Единый список внешних источников, на которые опирается «Главный». Подробности, цитаты и степень сверки — в
документах по ссылкам; адреса приведены только там, где они уже есть в этих документах.

## 1. Кейс

- КосмоХакатон 2026, кейс «Интеллектуальный контроль качества деталей в космической отрасли»: постановка и критерии
  оценки (два PDF организаторов). Построчное соответствие — [case-compliance.md](case-compliance.md), путеводитель
  по критериям — [reviewer-guide.md](reviewer-guide.md).

## 2. Стандарты и нормы

Сверены по официальным изданиям; ссылки на издания и статус — [normative-anchors.md, §7](normative-anchors.md#7-источники-официальные-издания).

| Стандарт | О чём |
|---|---|

| ГОСТ Р 58633-2020 | Космические системы: управление критичными и специальными процессами |

## 4. Документация внешних систем

Пометки «проверено по документации» и «проектное предположение» стоят построчно в описаниях интеграций.

| Система | На что опирались | Где у нас |
|---|---|---|
| 1С:ERP Управление предприятием 2.5, 1С:ERP Управление холдингом | открытые материалы 1С и интеграторов: стандартный интерфейс OData v3, коды ошибок OData, HTTP-сервисы расширения конфигурации | [integrations/1c.md](integrations/1c.md) |
| Галактика ERP 9.x | открытая документация модулей, касающихся ОТК; публичной спецификации API нет — форматы обмена проектные | [integrations/galaktika.md](integrations/galaktika.md) |
| MES | ISA-95 / IEC 62264, сообщения B2MML (MESA International) | [integrations/mes.md](integrations/mes.md) |
| КОМПАС-3D | документация SDK: COM API5 и API7; вместо САПР — файл условной сборки | [integrations/kompas.md](integrations/kompas.md) |
| СКУД | проектная модель событий прохода | [integrations/skud.md](integrations/skud.md) |

Эталонные сообщения со схемами — [integrations/examples/](integrations/examples/README.md).
