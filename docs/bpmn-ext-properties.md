# Свойства расширения BPMN `urn:ant:bpmn-ext:1`

Расширение BPMN 2.0 системы ant (AD-17, FR-12, FR-156): свойства элементов процесса в extensionElements пространства urn:ant:bpmn-ext:1. Источник схемы: из дескриптора генерируются Go-структуры XML, XSD и таблица документации (эпик 02). Значения перечислений и обязательность — contracts/bpmn-ext/rules.yaml.

Элементы пишутся внутри `bpmn:extensionElements` узла с префиксом `ant:`. Допустимые значения и обязательность — `contracts/bpmn-ext/rules.yaml`; XSD — `contracts/bpmn-ext/ant.xsd`.

## `ant:properties`

Свойства шага: стабильный ключ, вид, цех и склад, специальный процесс, буфер, закрытие доступа к зоне, заверитель бумажной подписи, закрывающая точка, точка контроля, лимит доработок, учётное действие, тип события-триггера, область таймера.

| Свойство | Тип | Где | Описание |
|---|---|---|---|
| `stepKey` | String | атрибут | Стабильный ключ шага, сохраняемый между версиями; смена смысла — новый ключ (AD-17). |
| `stepKind` | String | атрибут | Вид шага: operation \| automated_inspection \| human_inspection \| movement \| storage. |
| `workshop` | String | атрибут | Цех (для дорожки) — id места вида workshop. |
| `warehouse` | String | атрибут | Склад цеха (для дорожки). |
| `specialProcess` | Boolean | атрибут | Специальный процесс (FR-151, ГОСТ Р 58633 п. 3.17). |
| `bufferPlace` | Boolean | атрибут | Буфер или место очереди (FR-12). |
| `closesZoneAccess` | String | атрибут | Зоны, доступ к которым закрывает шаг, через пробел (FR-20). |
| `paperAttester` | String | атрибут | Роль заверителя бумажной подписи на шаге (AD-43); у заверителя — полномочие paper_attestation в области. |
| `closingPoint` | String | атрибут | Закрывающая точка: ZT-1…ZT-6, ZT-4.1, ZT-4.2, ZT-R, ZT-V. |
| `inspectionPoint` | String | атрибут | Точка контроля: KT-1…KT-5, KT-4d. |
| `operationCode` | String | атрибут | Операция по маршрутной карте. |
| `reworkLimit` | Integer | атрибут | Лимит повторов или доработок (FR-18). |
| `reworkLimitScope` | String | атрибут | К чему лимит: item \| zone \| loop. |
| `erpAction` | String | атрибут | Учётное действие на событии-сообщении «в 1С» (AD-18). |
| `triggerEventType` | String | атрибут | Тип события каталога, которое запускает стартовое или промежуточное событие-сообщение (решение Д-5). |
| `timerScope` | String | атрибут | Для граничного таймера: until_started — окно до начала операции; activity — всё время шага. |
| `outcome` | String | атрибут | Для конечного события вызываемого подпроцесса: значение переменной nc.outcome в точке вызова. |

## `ant:inspection`

Метод контроля и покрытие видов дефектов (FR-12, FR-14).

| Свойство | Тип | Где | Описание |
|---|---|---|---|
| `method` | String | атрибут | Метод контроля (defs.v1.json#/definitions/inspection_method). |
| `phase` | String | атрибут | Фаза контроля. |
| `coverage` | String | атрибут | Коды видов дефектов классификатора, которые метод способен выявить, через пробел. |
| `recipeRef` | String | атрибут | Карта контроля `‹id›@‹версия›`. |
| `observationQualityMinBp` | Integer | атрибут | Порог качества наблюдения, б. п.: ниже — «оценка невозможна». |

## `ant:presentationPoint`

Точка предъявления: полномочие, роль, срок ожидания, эскалация при повторном предъявлении (FR-19).

| Свойство | Тип | Где | Описание |
|---|---|---|---|
| `authority` | String | атрибут | Полномочие подписи. |
| `role` | String | атрибут | Роль. |
| `stampKind` | String | атрибут | Вид цифрового клейма. |
| `waitLimitMinutes` | Integer | атрибут | Срок ожидания, минут. |
| `waitLimitWorkDays` | Integer | атрибут | Срок ожидания, рабочих дней. |
| `repeatAuthority` | String | атрибут | Полномочие при повторном предъявлении (уровнем выше). |
| `customerAcceptance` | Boolean | атрибут | Изделие в перечне приёмок ПЗ/ВП — нужна подпись представителя заказчика. |

## `ant:normRef`

Нормативная опора для слоя «нормы» (FR-156): пункт стандарта, что проверить, что делает система; только из проверенного перечня norm-anchors.yaml.

| Свойство | Тип | Где | Описание |
|---|---|---|---|
| `standard` | String | атрибут | Стандарт. |
| `clause` | String | атрибут | Пункт. |
| `check` | String | вложенный элемент | Что проверить на шаге. |
| `systemAction` | String | вложенный элемент | Что делает система на шаге. |
