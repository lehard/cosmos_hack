# Руководства пользователей «Главного»

Руководства ролей для тех, кто работает в системе (FR-117). Тот же текст встроен в интерфейс: кнопка «Справка для вашей роли» в шапке открывает раздел своей роли без сети. Источник встроенной справки — `frontend/src/shared/help/content/`; файлы там и здесь совпадают побайтно, это проверяет `node docs/scripts/check-docs.mjs`.

Проверяющим — [путеводитель по критериям оценки](../reviewer-guide.md).

## Подпись решений

[sign_extension.md](sign_extension.md) — расширение браузера «Главный — подпись»: установка в Chrome, Chromium и Яндекс Браузер, загрузка ключей под PIN, разрешение адреса стенда, проверка индикатора «Токен» и подписи, неполадки и что делать (в том числе «Агент токена не найден» при установленном расширении). Во встроенной справке — адрес `/help/sign_extension`.

## Как устроена справка

- Раздел справки выбирается по столу роли: поле `help_key` стола (`normative/desks/‹роль›.yaml`), иначе — собственная роль, иначе — роль, чей стол достался по наследованию (например, держатель КД видит руководство согласующего).
- Формат — упрощённый markdown: заголовки, абзацы, списки «- ». Таблиц, ссылок и выделения в руководствах нет — их не показывает встроенная справка.
- Новая роль получает справку новым файлом в обоих каталогах; код менять не нужно.
