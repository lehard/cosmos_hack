# Материалы процессной сессии

Документы процессной сессии по фланцу люка: находки команды, паспорта контрольной точки и допуска, методы обнаружения, предложения, экраны и описательная схема процесса. Все изделия, числа, даты и люди — условные, из сюжета «плохой день сварочного участка». Статусы внутри документов — на момент процессной сессии; как есть в коде — [case-compliance.md](../case-compliance.md).

**Термины.** Документы приведены к словам системы: «блок / заблокировано», статус поста «Остановлен (блок)»; предложения показывает система в блоке «инженерная справка» — внутренний помощник подсказывает, но не решает. В описательной схеме и в данных сценариев остались слова процессной сессии («удержание», «придержано») — это то же самое, что «блок».

## Схема процесса v0.3.2

`flange-process-v0.3.2.bpmn` — **описательная схема процессной сессии**, актуальная её версия: нестандартные случаи S18–S22, процессы сигнала, разбора причин, сбоя оборудования и блокировки. **Исполняемая схема — в `normative/`** (на базе v0.1); по ней работает система; v0.3.2 — целевое описание процесса с расширенными случаями. Процессы, кроме процесса изделия, — описательные.
