# scenarios

Тестовые сценарии идут через обычный вход и сверяются с отдельно хранимым ожидаемым (AD-26).

| Каталог | Что | Эпики |
|---|---|---|
| `definitions/` | входные события сценариев | 09, 32 |
| `expected/` | ожидаемые результаты, хранятся отдельно от входа (кейс §5.1) | 09, 32 |
| `fixtures/` | мир заготовок для режима `fixtures` (AD-36) | 09 |
| `crypto/` | тест-векторы криптопрофилей | 05, 27 |
| `load/` | профили нагрузочного прогона (FR-107) | 35 |
