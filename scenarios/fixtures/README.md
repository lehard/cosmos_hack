# Мир заготовок (AD-36, FR-129, FR-150)

Режим `fixtures`: ведущие порты модулей отвечают отсюда через настоящий API и общий декоратор прав. Заготовки — не макет: тела — типы `application/‹модуль›`, проверяются схемами `contracts/openapi.yaml` в `make check`.

| Файл | Что | Кто пишет |
|---|---|---|
| `‹сценарий›/world.yaml` | компактное описание мира: изделия и вехи маршрута, несоответствия, области риска, 1С, сбои, шаги курсора | руками |
| `‹сценарий›/scenario.yaml` | оглавление: шаги, часы, ожидания решения человека, правила префикса прогона | генератор |
| `‹сценарий›/steps/NN.yaml` | ответы шага по `operationId` и параметрам; шаги накопительные — только изменившиеся ответы | генератор |
| `common/responses.yaml` | демо-персоны, сеансы, столы ролей (из `normative/policy`, `normative/desks`) | генератор |
| `common/blobs/` | большие неизменные строки (BPMN XML); в теле — `"@blob:‹имя›"` | генератор |

Пересобрать после правки `world.yaml` или нормативного слоя:

```
go test ./internal/infrastructure/fixtures/world -update   # в каталоге backend/, в контейнере Go
```

Без `-update` тест требует, чтобы файлы совпадали с генератором; `TestBodiesMatchOpenAPI` проверяет тела схемами, `TestMainStory` — область 34 → 13 → 6 и табло «ожидалось → получилось».

Формат ответа: `op` — operationId; `params` — HTTP-параметры операции (path + query) без момента (`axis`, `as_of`, `run_id`) и страницы; из подходящих берётся самый точный. ID хранятся без префикса прогона: рантайм добавляет `‹run_id›/` к локальным ID (`local_ids`) в ответе и снимает во входе (AD-38). Момент `as_of` — последний шаг с часами ≤ `as_of`. seq на шаге n: записи — `n·10000+1…`, `basis_seq` сводок — `(n+1)·10000−1`.

Рантайм (`backend/internal/infrastructure/fixtures/loader`): курсор (`FixtureCursor`: память или Postgres `fixtures.cursor`), старт прогона, пауза, скорость ×1…×1000, остановка на шаге `wait` до решения человека (команда `wait.action` над `wait.object` двигает курсор дальше). Образ `ant` строит мир в памяти тем же генератором; `ANT_FIXTURES_DIR` — читать этот каталог.
