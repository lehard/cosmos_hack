## Ожидается

- По проверке — «нет данных», а не «годно» — `S17-02`.
- ЗТ-СР закрыта, задачи мастеру и ОТК — `S17-03`.
- Проверка выполнена отдельной записью со ссылкой на отметку пропуска — `S17-04`.
- ЗТ-СР пройдена после проверки; отметка пропуска осталась в истории — `S17-05`.

## Чего не должно случиться

- Нет записи «нарушение», «ошибки исполнителя», рейтинга — `S17-N1`.
- Честно отметивший не хуже промолчавшего: за отметку ничего не начисляется — `S17-N2`.
- Пропуск проверки — не дефект: нет сигнала и несоответствия — `S17-N3`.
- ЗТ-СР не пройдена раньше проверки — `S17-N4`.
