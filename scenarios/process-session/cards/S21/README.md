# S21. Смешение партий: кольца П-116 и П-117 (после претензии)

> Все изделия, числа, ID, даты и люди — условные.
> Статус: сценарий и данные готовы. Как система проходит сценарий — по плану, проверить по факту у разработчиков.

**Где идёт.** Отдельный короткий прогон в своём мире, Чт 17.09 – Чт 24.09. Нестандартный случай (критерий О1).

## Проверяет

- **Постановка:** §4.6 — сборка и компоненты, генеалогия; §4.2 — входной дефект, круг по партии; §3.2 — журнал критических действий.
- **Строки листа:** ОК-1 «Понимание отрасли» (10) — прослеживаемость партий; ОК-2 и ТК-6 (15 + 15); ОК-3 и ТК-7 (15 + 15) — генеалогия по скану; ТК-2 (12) — возврат поставщику в 1С; ТК-3 (5).

## Исходное состояние

- У партии колец (патрубков) П-116 ещё есть кольца К-031…К-033. Во вторник кольца К-107 и К-108 партии П-117 по ошибке положили в тару П-116.
- В среду 15:45 по П-117 — претензия поставщику, как в главной истории.

## Действие

Во вторник кладовщик берёт кольцо из тары П-116 под Ф-034 — скан читает К-107 партии П-117. Партия тогда годна, кольцо выдают и вваривают. В среду после претензии система по генеалогии находит Ф-034, ставит его в круг по партии и блокирует; технолог исключает его по рентгену тела кольца. В четверг кладовщик берёт из той же тары К-108 под Ф-036 — скан: «партия заблокирована», выдачи нет. ОТК-2 проверяет тару сканом, К-108 уходит в изолятор, под Ф-036 выдают К-033.

## Ожидается

- Генеалогия идёт по коду кольца, а не по бирке тары — `S21-01`.
- После претензии партия заблокирована, в 1С — возврат 9 колец — `S21-02`.
- Ф-034 по генеалогии в круге по партии; исключён по рентгену — `S21-03`, `S21-04`.
- Скан К-108 при выдаче — «партия заблокирована», выдачи нет, запись в журнале — `S21-05`.
- Тара проверена сканом, К-108 в изоляторе; система показывает, куда раньше ушли кольца партии — `S21-06`, `S21-07`.

## Чего не должно случиться

- К-108 не выдано и ни к чему не привязано — `S21-N1`.
- Ф-034 не исключён без основания — `S21-N2`.
- По отклонённой выдаче в 1С ничего не уходит — `S21-N3`.
