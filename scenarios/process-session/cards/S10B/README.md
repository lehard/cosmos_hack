# S10-Б. Лимит переделок участка шва — отдельный прогон на Ф-090

> Все изделия, числа, ID, даты и люди — условные.
> Статус: сценарий и данные готовы. Как система проходит сценарий — по плану, проверить по факту у разработчиков.

**Где идёт.** Отдельный короткий прогон, Пн 28.09. В 4 минуты не входит.

## Проверяет

- **Постановка:** §4.3 — повторная обработка; §4.6 — повторное выполнение со связью с прежним; правило ТП «не больше трёх переделок участка шва, вторая и третья — с согласия главного сварщика» [ПП].
- **Строки листа:** ОК-2 и ТК-6 «Сквозной процесс» (15 + 15) — повторные операции; ОК-1 «Понимание отрасли» (10); ТК-3 «Аудит» (5) — отказы; ТК-2 (12) — одно сообщение в 1С.

## Исходное состояние

- Участок У4 фланца Ф-090 уже переделан по ТП три раза. Перед каждой переделкой — выборка и контроль выборки; вторая и третья — с согласия главного сварщика отдельной записью.

## Действие

Камера снова видит подрез на У4, ОТК подтверждает. После выборки пытаются запустить пятую сварку участка (четвёртую переделку). Потом пробуют решение «переделка» и «ремонт» без разрешения на отклонение. В конце — «списать».

## Ожидается

- Лимит достигнут, пятая сварка участка заблокирована — `S10B-01`.
- Запись в журнале критических действий, задача технологу — `S10B-02`.
- «Переделка» сверх лимита — отказ «лимит исчерпан» — `S10B-03`.
- «Ремонт» без разрешения на отклонение — отказ — `S10B-04`.
- Доступны только «ремонт по разрешению на отклонение» и «списать» — `S10B-05`.
- История переделок: выборка, контроль, согласие главного сварщика — где положено — `S10B-06`, `S10B-07`.
- MES (v0.3.1): четыре сигнала — четыре «не выдавать»; три «можно выдавать» по решениям «переделка»; после «списать» блок остаётся — `S10B-08`.

## Чего не должно случиться

- Четвёртой переделки нет ни в каком виде: запуск и решение блокируются — `S10B-01`, `S10B-03`.
- «Перевод в брак (переделка)» в 1С уходит один раз, при первом решении; дальше только «списание». В YAML отдельного утверждения нет — проверяется по `erp_outbox_expected` в `S10B.yaml`.
