# S04. Недостаток сведений — блик на Ф-025 и потерянные данные Ф-019

> Все изделия, числа, ID, даты и люди — условные.
> Статус: сценарий и данные готовы. Как система проходит сценарий — по плану, проверить по факту у разработчиков.

**Где идёт.** Главная история: часть Б — Ср 23.09 12:05–12:15, часть А — Ср 12:35–13:25. В защите — 1:30–2:20.

## Проверяет

- **Постановка:** §4.2 «недостаток сведений для вывода»; §5.1 «Неопределённость» — нет категоричного вывода; §4.5 — плохое наблюдение не равно годности; §4.6 — явное «неизвестно».
- **Идея «следующее лучшее наблюдение»:** при неопределённости система предлагает, какое наблюдение снимет её быстрее всего, — только из того, что допущено картой контроля. Назначает человек или правило.
- **Строки листа:** ОК-3 и ТК-7 «Сбор и обработка данных» (15 + 15) — пропуски; ОК-2 и ТК-6 «Сквозной процесс» (15 + 15); ОК-5 (5).

## Исходное состояние

- Ф-025 и Ф-021 попали в круг из шести (S05), им назначена перепроверка камерой и рентгеном.
- В карте контроля КТ-3 `RCP-CP-WELD@3` допущены четыре профиля съёмки [ПП]: «штатный» `KT3-STD`, «боковой свет» `KT3-SIDE`, «второй ракурс» `KT3-VIEW2`, «увеличенная зона» `KT3-ZOOM`. Пересъёмок участка — не больше 2. Корень шва и внутренние поры камера не видит: для них рентген.
- Во Вт 16:40–17:15, пока варили Ф-019, у шлюза ИС-2 переполнился буфер: 35 записей журнала потеряны навсегда.

## Действие

**Часть А.** Камера снимает шов Ф-025 по штатному профилю: «признаков нет», уверенность 0,91, но качество кадра 0,34 (блик, прижим закрыл У6–У7). Порог 0,6 — значит «оценка невозможна». В 12:41 система предлагает следующее наблюдение: снять прижим и переснять У6–У7 профилем «боковой свет», чтобы отделить блик от геометрии. Это предложение, не решение. Прижим снимает человек, поэтому по правилу край сам не переснимет: в 12:45 пересъёмку назначает ОТК-1 — первая из двух допустимых. В 12:55 второй кадр ссылается на первый: качество 0,88, признаков нет. Вывод по КТ-3 сделан на основании двух наблюдений. Дальше рентген.
**Ф-021 — обратный случай.** Кадр камеры в 12:35 чистый, а в 12:50 рентген находит прожог в корне шва на У5. Камера корень не видит, поэтому пересъёмку для него не предлагают: следующее наблюдение — рентген.
**Часть Б.** Шлюз досылает журнал ИС-2 с дырой в номерах записей. Для Ф-019 параметров сварки нет — деталь серая.

## Ожидается

- Исходный результат кадра сохранён как есть, рядом — производный «оценка невозможна» с причиной; корзина «оценка невозможна» +1 — `S04-01`, `S04-02`, `S04-07`.
- система предложила следующее наблюдение: профиль «боковой свет» из карты КТ-3, «отделить блик от геометрии», снять прижим. Статус — «открыто», решает ОТК — `S04-11`.
- У события «назначена повторная съёмка» есть причина (блик, прижим), профиль, почему он, ссылка на предложение, кто назначил (ОТК-1, не правило) и лимит «пересъёмка 1 из 2». Профиль — только из допущенных в карте — `S04-12`, `S04-13`.
- Второй кадр ссылается на первый; «признаков нет» — вывод на основании двух наблюдений; «пройдено с первого раза, но с доп. проверкой» — `S04-14`, `S04-15`, `S04-05`, `S04-06`.
- Ф-021: прожог в корне нашёл рентген; чистый кадр камеры для корня — «этим методом не проверяется»; следующее наблюдение — рентген, не пересъёмка — `S04-16`, `S04-17`.
- Ф-019 в круге — «нет данных» (серая), сказано, чего не хватает; потеряно у источника 35 записей, окно Вт 16:40–17:15 — `S04-08`, `S04-09`, `S04-10`.

## Чего не должно случиться

- Кадр с качеством 0,34 не даёт «годно» — `S04-N1`.
- Серая деталь не становится зелёной сама — `S04-N2`.
- Ток для Ф-019 не «дорисован» по соседним записям — `S04-N3`.
- «Оценка невозможна» не считается ни годностью, ни браком — `S04-N4`.
- Предложение системы само пересъёмку не назначает — `S04-N5`.
- Профиля вне карты `RCP-CP-WELD@3` и третьей пересъёмки участка нет — `S04-N6`.
- Для корня шва и внутренних пор (Ф-021, Ф-023) пересъёмку не предлагают — `S04-N7`.
