# I1. Обмен с 1С: задание, учёт на закрывающих точках, ошибки и повтор

> Все изделия, числа, ID, даты и люди — условные. Виды сообщений 1С — наши рабочие, окончательные задают разработчики.
> Статус: сценарий и данные готовы. Как система проходит сценарий — по плану, проверить по факту у разработчиков. Утверждения с пометкой [П] — наше предложение «результат контроля», ждёт решения разработчиков.

**Где идёт.** Главная история целиком, Пн 14.09 – Чт 24.09.

## Проверяет

- **Постановка:** §5.3 — входящее задание, исходящий результат, ID объектов и сообщений, подтверждение или ошибка; §3.3 — интеграции; §1.5 п. 1 и п. 7.
- **Строки листа:** ТК-2 «Архитектура и системные интеграции» (12) — двусторонний обмен и обработка ошибок; ОК-2 и ТК-6 (15 + 15); ОК-1 (10); ТК-3 (5).

## Исходное состояние

- Stand 1С отвечает на сообщения. Таблица соответствий ID заполнена, кроме договора с Поставщиком-3.

## Действие

1С присылает задание на 40 фланцев. Система отправляет в 1С только учётные движения на закрывающих точках. Первая отправка «выпуска годного» Ф-001 получает 503 — повтор с тем же номером проходит. «Возврат поставщику» получает 422 «не найден договор» — без автоповтора, задача администратору; он добавляет соответствие, повтор проходит.

## Ожидается

- Задание из 1С принято и связано с внутренним ID — `I1-01`.
- Ошибка 503: повтор с тем же номером сообщения, подтверждено — `I1-02`.
- Ошибка 422: без автоповтора, исправил администратор, подтверждено — `I1-03`, `I1-04`.
- Итог для защиты: 6 в брак (переделка), 1 возврат поставщику — `I1-05`.
- У каждого сообщения есть ответ; «учтено в 1С» — только по подтверждению; отправка не держит изделие — `I1-06`, `I1-07`.
- [П] «Результат контроля» после подписанных ЗТ — `I1-08`, `I1-09` (ждёт решения разработчиков).
- MES (v0.3.1): «не выдавать в работу» — в момент блока по каждому заблокированному изделию и партии (43); «можно выдавать» — только по решению человека (41) — `I1-10`, `I1-11`.

## Чего не должно случиться

- В 1С не уходят сигналы, наблюдения, журналы, гипотезы — `I1-N1`.
- При воспроизведении истории в 1С ничего не отправляется — `I1-N2`.
- Повтор не проводит документ дважды — `I1-N3`.
- «Выпуск годного» не раньше подписанной ЗТ-6 — `I1-N4`.
- В MES нет гипотез и причин; «можно выдавать» не уходит без решения человека и после «списать» или «вернуть» — `I1-N6`, `I1-N7`.
