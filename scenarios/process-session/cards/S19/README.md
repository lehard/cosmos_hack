# S19. Изменили КД посреди партии: ревизия «Б» → «В» (извещение ИИ-ФЛ-100-07)

> Все изделия, числа, ID, даты и люди — условные.
> Статус: сценарий и данные готовы. Как система проходит сценарий — по плану, проверить по факту у разработчиков.

**Где идёт.** Отдельный короткий прогон в своём мире (остаток заказа ЗП-0917), Пт 25.09 – Пн 28.09. Нестандартный случай (критерий О1).

## Проверяет

- **Постановка:** §4.6 — версии и ревизия КД у каждого изделия; §3.3 — КОМПАС-3D и 1С; допуск ИИ: новая ревизия — ручной контроль, пока нет допуска.
- **Строки листа:** ОК-1 «Понимание отрасли» (10) — работа с заделом; ОК-2 и ТК-6 (15 + 15); ТК-2 «Интеграции» (12) — ревизия из КОМПАС, номенклатура и списание в 1С; ОК-3 и ТК-7 (15 + 15) — ревизия у записи.

## Исходное состояние

- Ф-037 и Ф-038 сварены по ревизии «Б», ЗТ-3 пройдена. Ф-039 мехобработан по «Б», ждёт рейса. Ф-040 ещё не запущен.
- Уплотнение старой конструкции на складе — одно.

## Действие

Из КОМПАС приходит ревизия «В» с извещением: отверстие D2 — 252 вместо 250 под новое уплотнение. Новые запуски идут только по «В». Начатые изделия система блокирует и показывает технологу. Он решает по каждому: Ф-039 — доработать до «В»; Ф-037 — оставить по «Б» по разрешению на отклонение (подписывает и ПЗ); Ф-038 — списать. Ф-039 растачивают на станке и принимают заново, Ф-040 запускают по «В». Камеры для «В» ещё не допущены — контроль вручную.

## Ожидается

- Ревизия «В» принята; новые запуски — только по ней; задел система составила сама — `S19-01`, `S19-02`.
- Задел заблокирован сразу; для «В» — ручной контроль вместо камеры — `S19-03`, `S19-04`.
- По каждому изделию — своё решение с причиной; разрешение подписано ПЗ — `S19-05`, `S19-06`.
- В 1С — только «перевод в брак (списание)» по Ф-038 — `S19-07`.
- Доработка — новое выполнение со ссылкой на прежнее; паспорт хранит ревизию каждого изделия — `S19-08`, `S19-09`.

## Чего не должно случиться

- Задел не выходит из блока без шага человека; списанный — не выходит совсем — `S19-N1`.
- Ф-037 не идёт дальше до подписанного разрешения — `S19-N2`.
- Задел не переписан на «В» задним числом — `S19-N3`.
- Смена ревизии — не несоответствие: нет сигналов и «перевода в брак (переделка)» — `S19-N4`.
