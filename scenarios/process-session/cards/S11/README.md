## Действие

Сборщик подносит крышку раньше, чем поставил уплотнение. OperatorVision замечает: «уплотнения в канавке не видно», уверенность 0,78. Маршрут блокирует шаг «установка крышки»: нет подтверждения уплотнения и предъявления зоны ОТК. Сборщик ставит уплотнение, камера зоны видит чистую канавку, ОТК-2 принимает скрытые работы (ЗТ-СР), крышка ставится.

- Шаг «установка крышки» остановлен до брака — `S11-02`.
- Дальше строго по порядку: уплотнение → зона чистая → ЗТ-СР → крышка — `S11-03`.
- Сборщик определён по входу на терминал, а не по лицу — `S11-04`.
- Без OperatorVision шаг блокируется по порядку маршрута — `S11-05`.
