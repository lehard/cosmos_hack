# S09. Подмена записи — обнаружена (три атаки)

> Все изделия, числа, ID, даты и люди — условные.
> Статус: сценарий и данные готовы. Как система проходит сценарий — по плану, проверить по факту у разработчиков. Способ восстановления исходного значения выбирают разработчики.

**Где идёт.** Главная история, Ср 23.09 16:30–17:01, разбор — Чт 24.09 07:45. В защите — 3:45–4:00 (атака 1).

## Проверяет

- **Постановка:** §4.2 «контрольное изменение записи для проверки целостности»; §5.1 «Изменение данных» — обнаружение нарушения; §3.4 — исходные события отдельно от изменяемых представлений, исправления — новыми записями.
- **Строки листа:** ТК-3 «Информационная безопасность и аудит» (5) — неизменяемый журнал, журнал критических действий.

## Исходное состояние

- Круг RS-01 сужен до 6 по записи EV-WS2-0412 (ток 176 А). Заключение рентгена по Ф-019 — основание входного брака (S02).
- Контрольная отметка цепочки уходит хранителю вне базы по расписанию.

## Действие

**Атака 1:** запись EV-WS2-0412 правят прямо в базе: 176 → 166 А. Администратор пробует «исправить» через программу — отказ.
**Атака 2:** «администратор БД» правит заключение рентгена по Ф-019 и пересчитывает цепочку — звенья сходятся.
**Атака 3:** правят только таблицу-представление: статус Ф-023 «в переделке» → «годно».
В Чт 07:45 начальник ОТК и администратор разбирают подмены новой записью.

## Ожидается

- Атака 1: нарушение найдено на этой записи; красная полоса на всех экранах — `S09-01`, `S09-02`.
- Исправление через программу — отказ, только новой записью — `S09-04`.
- Зависимые выводы помечены «основание под вопросом» — `S09-05`, `S09-09`.
- Атака 2 найдена по подписи источника и отметке вне базы — `S09-06`.
- Атака 3 найдена сверкой с журналом, представление пересобрано — `S09-07`.
- В журнале критических действий три нарушения; разбор — новой записью, метки сняты — `S09-08`, `S09-10`.

## Чего не должно случиться

- Круг не пересчитывается по подменённому значению (остаётся 6) — `S09-N1`.
- Решения людей и сообщения 1С не отменяются сами; претензия поставщику тоже — `S09-N2`, `S09-N5`.
- Ф-023 не двигается по подменённому статусу — `S09-N3`.
- До разбора ни одна ЗТ по Ф-015 и Ф-019 не подписана — `S09-N4`.
